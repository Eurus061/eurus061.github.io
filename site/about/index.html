WORKSTATION & OS

主机与运行环境

  • Windows 11 + WSL2 / Ubuntu主力桌面工作与 Linux 实验环境分离

    日常编码与浏览器验证留在桌面侧，构建与抓包复现集中在隔离 Linux 子系统。

  • Docker 隔离实验容器可销毁的靶场、代理与验证沙箱

    保持宿主机环境干净，每组漏洞复现或网络验证使用独立 compose 拓扑。

  • Nginx + HTTPS 静态与反代层全站零数据库静态托管 + 受控评论反代

    只暴露必要 TLS 端口与严格白名单路径，历史 WordPress URL 保持 301/映射兼容。

EDITOR & TERMINAL

编辑器与终端

  • VS Code / Neovim主力 IDE 与终端快改组合

    TypeScript/Astro 工程依赖语言服务与静态校验，远程服务器配置修改使用轻量化 Vim 键位。

  • Windows Terminal / Zsh + tmux多窗格会话与双机联调终端

    搭配 JetBrains Mono 等宽字体，区分构建监控、日志观察与测试回归窗格。

  • Git + GitHub Actions 双仓发布引擎仓与内容仓解耦 + SHA-256 增量协商

    任何发布包须先经过前端类型、对比度、本地链接与资产白名单校验。

SECURITY TOOLKIT

安全研究与排查

  • Wireshark / tcpdump链路层抓包、TLS 握手与异常重传分析

    先拿真实报文时间线与五元组证据，再判断策略拦截或协议栈行为。

  • Burp Suite / mitmproxyHTTP(S) 流量审计与脚本化中间人观测

    验证鉴权边界、请求重放与客户端证书校验逻辑。

  • nmap / 站内离线安全工具箱端口边界扫描与常用编码/JWT/哈希/正则工作台

    日常 Token 排查与文件摘要优先在纯本地 Web Crypto 环境完成。

BLOG & WRITING

站点与写作体系

  • Astro 7 + React 19 + TypeScript纯静态 HTML 优先 + 按需交互孤岛

    常规页面零冗余运行时开销，仅搜索面板、终端与工具台挂载客户端脚本。

  • Markdown / MDX + Shiki + Mermaid / KaTeX本地离线公式与图表按需加载管线

    不引用外部字体或 CDN，图表支持深浅主题重绘与源码回看。

  • 独立隔离 Waline + 本地全文检索静态主站之外的受限评论节点与离线索引

    兼顾零追踪阅读体验、可审计构建与历史迁移资产完整性。

WHY THIS BLOG

关于这里

这个博客整理我在网络安全、网络工程和 AI 技术实践中的观察与思考。比起只留下结论，我更希望把问题是如何被理解、验证和解决的过程写清楚。

技术文章之外，也会记录一些日常与随笔。它们共同组成这个静态优先、无冗余追踪的个人博客。

WRITING DISCIPLINE

为什么继续写
